ファインマンが1948年に提唱した経路積分は、2020年代に単一光子実験による直接検証が報告されている（華南師範大学のチームが141万9857通りの経路の確率振幅を再構成し、約95%の一致度を確認）。このノートは、経路積分の基本仮説から出発して、光や粒子が示す4つの異なる顔——直進性・反射・回折・トンネル効果——が、実はすべて同じ1つの原理の異なる現れ方にすぎないことを整理する。

---

## 出発点——2つの仮説

ファインマンの経路積分は、次の2つの仮説に立つ。

1. 粒子（光子を含む）は、始点から終点までの**あらゆる経路を同時に通る**
2. 各経路の波は**振れ幅が等しく、位相のみが異なる**（$e^{iS/\hbar}$、$S$は作用）

位相は経路に沿った運動量の積分にほぼ対応する（$S\sim\int p\,dx$）。つまり運動量ベクトルは経路と切り離された別の実体ではなく、「その経路がどれだけ速く位相を回転させるか」を決める量にすぎない。観測される現象は、無数の経路の位相同士が干渉した結果として決まる。

---

## 直進性——なぜ1本の光線に見えるか

無数の経路をすべて足し合わせても、直進から大きく外れた経路は光路長（位相）が経路ごとに大きく異なるため、隣接する経路同士で位相がすぐにずれて打ち消し合う。一方、光路長が停留する経路（変化が一次近似でゼロになる経路）の近くだけは、隣接する経路の位相がほぼ揃っているため、打ち消し合わずに強め合う。これが**停留位相の原理**であり、光学のフェルマーの原理（最短時間の経路）と同じものである。

生き残る経路の幅は無限に細い1本ではなく、フレネルゾーンと呼ばれる帯（幅 $\sim\sqrt{\lambda L}$、$\lambda$=波長、$L$=伝搬距離）を持つ。波長が伝搬距離に対して相対的に短くなるほどこの帯は無視できるほど細くなり、見かけ上「1本の光線」として直進する。これが幾何光学の極限（$\lambda\to0$）である。

## 反射——鏡面全体を使った停留位相

鏡による反射も同じ論理で説明できる（ファインマンが著書『QED：光と物質のふしぎな理論』で有名にした例）。経路積分では、光は鏡面上のあらゆる点で反射する経路を同時に足し合わせている。鏡の端の方で反射する経路は光路長が大きくばらつき打ち消し合うが、「入射角＝反射角」となる点の近くだけは光路長がほとんど変わらず（停留位相）、強め合う。結果として鏡全体を使っているにもかかわらず、あたかも1点だけで跳ね返ったかのような正反射の法則が現れる。

## 回折——停留位相近似が崩れる場所

開口やエッジのサイズが波長 $\lambda$ と同程度まで小さくなると、フレネルゾーンの幅が開口のスケールに対して無視できなくなり、「停留位相点の近くだけが生き残る」という近似そのものが崩れる。より広い範囲の経路が寄与するようになり、光が直進せずに広がって見える。これが回折であり、可視光のように波長が短い場合は日常サイズの開口では無視できるが、電波（波長が長い）では建物の陰にも回り込むほど顕著になる。

なお、干渉は完全な相殺（暗線・暗点）も生む。二重スリットの暗い縞や、円形障害物の影の中心が逆に明るくなるポアソン・アラゴ班点（周囲を回り込む経路が対称性のため同位相で強め合う）は、この停留位相ロジックの裏面にあたる。ただし個々の点で振幅がゼロになっても、エネルギーは空間全体で保存されており、光そのものが消滅するわけではない。

## トンネル効果——禁止領域には競合する実数経路が存在しない

障壁の中（古典的に $E<V$ となる領域）には、そもそも実数の古典軌道が存在しない（運動エネルギーが負になるため）。したがって「たくさんの実数経路が打ち消し合う中で偶然生き残った外れ値」という描像は成り立たない。

数学を複素数（あるいは虚数時間）の経路にまで拡張すると、実数の世界に停留点がなくても、複素平面上に別の停留点（鞍点）が見つかる。これが**インスタントン**である。ただしこの複素の停留点は、実数の場合のように振動して強め合うのではなく、指数関数的に減衰する実数の値（$e^{-S_E/\hbar}$）を生む。波動関数で見ても同じ結論になる——禁止領域では波数 $k=\sqrt{2m(E-V)}/\hbar$ が虚数になり、振動が指数減衰（$e^{-|k|x}$）に置き換わるだけである。

トンネル効果は毎回同じ値を与える決定論的な量であり、統計的なゆらぎ・外れ値ではない。

### 「時間を遡っている」わけではない

虚数時間（$t\to-i\tau$、ウィック回転）は、振動する発散しやすい積分を、滑らかに収束するユークリッド積分に変換するための**計算上のトリック**であり、粒子が実際に過去に向かって進んでいるわけではない。計算が終われば実時間に解析接続し戻すことで、初めて観測可能な物理量（トンネル確率など）が得られる。

紛らわしいが別物の話として、反粒子を「時間を過去向きに進む粒子」として描くファインマン＝シュテュッケルベルク解釈や、障壁が厚くなっても通過時間があまり増えないように見えるハートマン効果（トンネル時間のパラドックス）があるが、いずれも因果律を破るものではない。

### ブラックホール内部との関係——似ているが別物

シュヴァルツシルト計量では、事象の地平面の内側で時間座標 $t$ と動径座標 $r$ の計量の符号が文字通り反転し、時間と空間の役割が入れ替わる。これは強い重力によって**実際に時空が歪んだ結果**（一般相対論の幾何学的な帰結）であり、地平面という物理的な境界を伴う。

一方トンネル効果の虚数時間は、粒子や周囲に何か物理的な力場が発生しているわけではない計算上の座標変換であり、重力も地平面のような物理的境界も必要としない（半導体のトンネル接合は地球上の弱い電場だけで起こる）。両者は「同じ数学的道具（虚数時間・解析接続）を使う」という点で共通するが、背後にあるメカニズムは別物である。

なお、ホーキング輻射の温度はまさにこの2つを橋渡しする——地平面近くの時空を虚数時間に解析接続し、円錐特異点を作らないための周期性から温度を導く（ギボンズ＝ホーキングの手法）。

### 量子ゆらぎとの関係——単純トンネルは近似、場の理論のトンネルは厳密に同じ

「不確定性原理でエネルギーを一時的に借りて障壁を超える」という通俗的な説明は、単純な1粒子のポテンシャル障壁トンネルには**厳密には当てはまらない**。教科書的な計算では、粒子のエネルギー $E$ は最初から最後まで保存されており、位置と運動量を同時に確定できないという量子力学の性質だけで説明がつく。

一方、場の理論のレベルでは、量子ゆらぎとトンネル効果が文字通り同じ数式で記述される厳密な接続点がある。

- **シュウィンガー効果**：強い電場中で、通常なら一瞬で消える仮想粒子対（量子ゆらぎ）が、実粒子対として飛び出す現象。インスタントンとしてトンネル効果と同じ数式で計算される
- **偽真空崩壊**：宇宙がより低いエネルギー状態に転移する過程を、虚数時間経路積分によるトンネル効果として記述する（コールマン＝デルッチアの理論）。[wiim_125](../physics/wiim_125.md)・[wiim_127](../physics/wiim_127.md) が扱う真空崩壊泡は、まさにこのインスタントン計算の帰結である

## 光子トンネリング——光学における実例

トンネル効果に直接対応する光学現象として、フラストレイテッド全反射（光子トンネリング）がある。全反射しているガラス面のすぐ外側には、指数関数的に減衰する滲み出し波（エバネッセント波）が存在する。ここに波長程度の距離まで別のガラスを近づけると、本来閉じ込められるはずの光がその隙間をすり抜けて向こう側に伝搬光として現れる。回折とは明確に区別される、光学におけるトンネル効果の実例である。

## 4つの現象を分ける基準

| 現象 | 経路の性質 | 数学的な仕組み |
|---|---|---|
| 直進性 | 許容領域、実数の経路 | 停留位相付近だけが強め合う（フェルマーの原理） |
| 反射 | 許容領域、跳ね返る実数の経路 | 同じく停留位相（入射角＝反射角） |
| 回折 | 許容領域、開口・エッジ付近 | 停留位相の近似が崩れ、広い範囲の経路が寄与 |
| トンネル効果 | 禁止領域を含む | 実数の停留点がなく、複素（虚数時間）の停留点が指数減衰項を与える |

何が起きるかを分けているのは、経路が許容領域にあるか禁止領域にあるか、停留位相点が鋭いか緩いか、跳ね返るか透過するかという**境界条件と幾何学的状況の違いだけ**であり、運動量ベクトルと全経路の重ね合わせは同時に起きる2つの別物ではなく、同じ1つの仕組みの表と裏である。

回折・トンネル効果のいずれも、系の長さのスケールが $\hbar$ に由来する量子的な長さ（回折では波長 $\lambda=\hbar/p$、トンネルでは滲み出し長 $1/\kappa=\hbar/\sqrt{2m(V-E)}$）と同程度かそれより短くなったときにだけ顕在化する。どちらも「$\hbar$ をある種の運動量で割った長さ」という同じ骨格を持ち、質量が大きいほどこの長さは短くなる。野球ボールが回折して見えたり壁をすり抜けたりしないのは、この基準の長さが原子よりもさらに短くなってしまうためである。

## 主な限定・注意点

| 論点 | 限定 |
|------|------|
| 「エネルギーを借りる」という説明 | 単純な1粒子トンネルには厳密には当てはまらない近似的な比喩。場の理論の対生成・真空崩壊では厳密に成り立つ |
| 虚数時間＝時間を遡る | 誤り。振動する積分を収束させるための解析接続であり、物理的な時間逆行ではない |
| ブラックホール内部の時空反転とトンネル効果の虚数時間 | 前者は一般相対論の幾何学的帰結（重力が必要）、後者は計算上のトリック（重力不要）。同じ数学的道具を使うが別メカニズム |
| シュウィンガー効果の直接観測 | 理論上必要な臨界電場（$\sim10^{18}$V/m）は未達成。固体中の類似現象は確認済みだが、真空中での直接観測は現在進行形の実験目標 |
| 我々の宇宙が偽真空かどうか | 標準模型の枠内では示唆されるが、未知の物理に依存するため未確定（[wiim_125](../physics/wiim_125.md) 参照） |
| トンネルにかかる時間 | ハートマン効果など、所要時間の定義自体に複数の理論的立場があり、アト秒レーザーを使った実験で検証が進行中 |
