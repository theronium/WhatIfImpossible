## 反重力天体・ネグレーザー系ブランチ

### 反重力天体系実現限界

| ノード | 根本的な障壁 |
|--------|------------|
| ネグレーザー | 真空ゆらぎに誘導放出相当のメカニズムが存在しない——コヒーレント化の物理的手段が未定義 |
| 反重力天体 | 量子不等式（フォード＝ローマン不等式）により天体スケールでの負エネルギー密度維持が原理的に不可能 |
| ネゴトロンビーム外部照射 | 負慣性質量下では電磁引力が実質的斥力に反転し、二つのネゴトンの重力もまた相互反発になる——古典的な束縛力が電磁力・重力のどちらの経路にも存在せず、不確定性原理が許す範囲の一時的な量子的余韻としてしか存在できない |
| ネゴトンホワイトホール | 負質量のシュヴァルツシルト解が一般相対論で物理的に意味を持つか未解決・排除地平線の形成条件が量子不等式を超える |
| 局所ビッグバン応用 | 崩壊のタイミング・規模・方向が制御不能——意図的応用より暴走的破壊になる可能性が高い |
| 反重力原子 | 強い力・電磁気力は質量に依存せず力自体は不変のまま、負質量の受け手側だけ加速度が反転する——クォークは核子に閉じ込められず、電子は軌道に留まれない。素粒子レベルでは4つの力すべてが同じ機構で反転し、複合的な「反重力原子」は構造として成立しない |
