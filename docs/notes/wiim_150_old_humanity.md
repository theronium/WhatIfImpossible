## 概要

[wiim_150](../biology/wiim_150.md) は、「消えた多形」の本質を次のように整理した。
**消えるのは物質ではなく、その形を作れる「種のない環境」である。**

このノートは、同じ構図を人類に当てはめる。
シェルマイセリウム（[wiim_025](../biology/wiim_025.md)）の中で育つ世代には、菌糸と意思を通わせる**感応者**（マイセリアン、[g299](../../glossary/terms/g299.md)）が現れる。
もし感応者を生む「種」——胞子や菌糸が出す分子——が人類の生活圏を満たしたら、どうなるか。
生まれる子どもは全員、生まれた瞬間から種に触れて育つ。
感応しない旧来の人間は、遺伝的には何も失っていないのに、**もう育てられなくなる**。

誰も滅ぼしていないのに、旧人類が消えていく。このノートでは、その社会・宗教・法の帰結を扱う。

---

## 前提：遺伝ではなく「育ち」で決まる形質

この代替わりが成り立つには、感応者らしさが遺伝ではなく、**育つ環境で種に触れて身につく形質**である必要がある。
遺伝で受け継がれる形質なら、種の有無に関係なく親から子へ伝わるので、「消えた多形」の構図は当てはまらない。

現実にも、生まれたときの環境で体の中身が変わる例はある。
たとえば赤ちゃんの腸内細菌の構成は、生まれ方や最初に触れる環境によって変わることが知られている。
感応者の形質も、このような「最初に何に触れたか」で決まる性質だと仮定する。

| 結晶の世界 | 人類の世界 |
|-----------|-----------|
| 準安定な結晶形 | 旧人類（感応しない人間） |
| より安定な結晶形 | 新人類（安定した感応者） |
| 種結晶 | 胞子・菌糸由来の分子 |
| 種で満たされた工場 | 胞子が行き渡った生活圏 |
| 種を除いた清浄な実験室 | 無菌の隔離居住区 |
| 遺伝ではない（同じ分子の並び方の違い） | 遺伝ではない（同じ遺伝子の育ち方の違い） |

## 代替わりの年表（段階則に沿って）

結晶はいきなり最も安定な形になるのではなく、まず準安定な形を経由しやすい（オストワルトの段階則）。
この経験則に沿うと、代替わりは次のように進むと考えられる。

| 段階 | 状態 | 社会の見え方 |
|------|------|-------------|
| **1. 散発期** | シェルマイセリウム内の世代に、数世代に一人の割合で感応者が現れる。能力は不安定で、ある日突然消えることもある | 感応者は珍しい存在として、崇拝と差別の両方を受ける（[コズミックマイスをめぐる信仰と社会](cosmic_myce_religion.md)） |
| **2. 安定型の出現** | ある世代に、能力が生涯消えない「安定した感応者」が生まれる | 最初は単なる強い感応者として扱われ、転換点だとは気づかれない |
| **3. 拡散期** | 安定型を生む種が、居住区の空気・水・食物を通じて広がる。新生児に占める感応者の割合が急に上がる | 「うちの子も感応者だった」が当たり前になる。旧人類の親が新人類の子を育てる家庭が増える |
| **4. 飽和期** | 胞子が行き渡った地域では、生まれる子のほぼ全員が感応者になる | 旧人類は高齢層だけになる。最後に生まれた旧人類の世代が「最後の世代」と呼ばれる |
| **5. 残存期** | 旧人類が生まれるのは、マイスのいない遠方植民地と無菌の居住区だけになる | 旧人類は少数派、または保全の対象になる |

段階1の感応者が不安定なのは、それが**まだ途中の準安定な形**だからだと読み直せる。
既存の設定で「感応者の能力が突然消える」とされていることは、この見方と矛盾しない。

## 規模と地域差

[wiim_150](../biology/wiim_150.md) の結論どおり、広がる範囲は種の届く範囲で決まる。

| 地域 | 種は届くか | 旧人類の行方 |
|------|-----------|-------------|
| シェルマイセリウム内の居住区 | 常に満ちている | 最も早く飽和する |
| テラフォーミングされた惑星（[wiim_026](../biology/wiim_026.md)） | 大気中の胞子で届く | 数世代で飽和すると考えられる |
| マイスの回遊ルートから外れた天体 | 人や物資の行き来でゆっくり届く | 交易が多いほど早く失われる |
| 密閉居住区・遠方植民地 | 検疫しだいで防げる | 旧人類が残る最後の場所になる |
| 他の恒星系 | 種はほぼ届かない | 代替わりは起きない |

代替わりは人類全体で一斉に起きるのではなく、**地域ごとに時差をもって進む**。
その結果、「旧人類しかいない星」と「新人類しかいない星」が同時に存在する時代が長く続くと考えられる。

## 旧人類保護区

現実の医薬品でも、種を厳密に取り除けば元の結晶形は再び作れた。
同じように、胞子を完全に遮断した**無菌の隔離居住区**でなら、旧人類を育て続けることはできる。

- **運営**：「旧人類保全運動」と呼ばれる世俗の運動が中心になる。宗派の「保護派」は人間ではなくコズミックマイスを守る立場なので、両者は名前が似ていても対立しやすい
- **コスト**：空気・水・食物・来訪者をすべて検疫し続ける必要がある。たった一度の漏れで、その世代は新人類として育つ
- **一方通行**：保護区の子が外に出れば、種に触れることになる。ただ、すでに育った大人が種に触れても新人類にはならないと仮定すると、外へ出ることは「自分の子が旧人類でなくなる」ことを意味する
- **問い**：保護区で育つ子は、自分で選んで旧人類になったわけではない。「人類の多様性を残すため」に、子どもを無菌の囲いの中で育てることは正当化されるか

## 宗派ごとの反応

| 宗派 | 代替わりへの態度 |
|------|----------------|
| **合一派** | 「人類全体の合一が始まった」と歓迎する。保護区を「救済を拒む囲い」とみなす過激派も現れる |
| **通訳派** | 感応者が多数派になると、「通訳」という役割そのものが不要になる。宗派としての存在意義が揺らぐ |
| **保護派** | マイスの胞子を人類が意図的に遮断・除去することを「知性体への干渉」として批判する。結果的に、旧人類保全運動と対立する |
| **進化派** | 「共進化の当然の帰結」として受け入れる。代替わりの原因を「汚染」と呼ぶことに強く反発する |
| **食べる派** | 摂食で種を体に取り込めば大人でも新人類になれるかを試す。成功例が出れば、代替わりは出生を待たずに進むことになる |

---

## 法と倫理の論点

- **誰が責任を負うのか**：誰も殺されず、誰の遺伝子も途絶えていない。それでも、ある「人間の形」がこの世から失われていく。この喪失は、誰かが責任を負う損害と言えるのか
- **出生地の選択**：子どもを保護区の内と外のどちらで産むかで、その子が旧人類になるか新人類になるかが決まる。親はこの選択をしてよいのか
- **意図的な種まき**：ある地域に胞子を意図的に撒けば、そこで生まれる次の世代を新人類に変えられる。これは文化の押しつけか、それとも一種の生物兵器か
- **自己決定**：大人は自分が旧人類であり続けるかどうかを選べない。代わりに、自分の子がどちらになるかを選ぶことしかできない

## マイセリアン・パニックとの違い

[マイセリアン・パニック](mycelian_horror.md) は、菌糸が大人の神経を乗っ取って意思を奪う、という恐怖の物語だった。
このノートの代替わりはその反対で、誰の意思も奪われない。
ただ、次に生まれてくる子どもたちが、最初から別の形で育つだけである。

恐怖の物語が「感染」を描くのに対し、こちらは**静かな交代**を描く。
暴力も事件もないため、社会が気づいたときにはすでに飽和期に入っている、という展開がありうる。
