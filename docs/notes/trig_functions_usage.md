# 三角関数・逆三角関数の使用場面——sin・cos・tanとarcの使い分け

衛星高度・軌道周期の計算でアークタンジェントが登場したのを機に、WIIMの各種計算で三角関数（sin・cos・tan）と逆三角関数（arcsin・arccos・arctan）がどのように使われているか、また今後どんな場面で使えるかを整理する。

---

## 1. 三角関数（sin・cos・tan）——「角度から比を求める」

単位円上の点 $(\cos\theta, \sin\theta)$ を基準に、直角三角形の辺の比として定義される。

| 関数 | 定義 | 直感的な役割 |
|------|------|------|
| $\sin\theta$ | 対辺 / 斜辺 | 「高さ」「垂直成分」を取り出す |
| $\cos\theta$ | 隣辺 / 斜辺 | 「奥行き」「水平成分」を取り出す |
| $\tan\theta$ | 対辺 / 隣辺 $= \sin\theta/\cos\theta$ | 「勾配」「高さと水平距離の比」を取り出す |

### WIIM内での使用例

| 関数 | 使用場面 | 出典 |
|------|---------|------|
| $\cos i$ | 太陽同期軌道の昇交点移動速度が軌道傾斜角 $i$ の余弦に比例する（$\dot\Omega_{\rm SSO}\propto\cos i$） | [人工衛星の特殊軌道](satellite_orbits.md) |
| $\cos\delta$ | アル・ビールーニーの地球半径測定——山頂からの沈み込み角（dip角）$\delta$ と山の高さ $h$ から $R=\dfrac{h\cos\delta}{1-\cos\delta}$ | [天体距離測定の歴史](astronomical_distance_history.md) |
| $\cos\alpha_0$ | GEOネックレスのカテナリーフラクタル収束深さ $\sum\Delta r_n \propto (1-\cos\alpha_0)$ | [wiim_105](../physics/wiim_105.md) |
| $\sin\theta,\cos\theta$ | オイラーの公式 $e^{i\theta}=\cos\theta+i\sin\theta$——複素平面上の回転、波動関数の位相表現 | [オイラーの主要定理一覧](euler_theorems.md) |
| $\tan p \approx p$ | 視差角 $p$ が十分小さいときの小角近似。$D = b/p$ という単純な割り算の裏側は実は $\tan$ | [天体質量の測定手法と静止軌道パラメータの導出](kepler_geostationary_derivation.md) |

**小角近似の注記**：$p$ が数秒角〜数分角のオーダーだと $\tan p \approx \sin p \approx p$（ラジアン）が成立し、三角関数を経由せず直接の比として扱える。年周視差のように角度が極めて小さい測定ではこの近似が常用される。

---

## 2. 逆三角関数（arcsin・arccos・arctan）——「比から角度を求める」

三角関数の逆演算。ただし三角関数は周期関数のため、逆関数は**値域を制限**して一価にしている。

| 関数 | 値域 | 制限の理由 |
|------|------|------|
| $\arcsin$ | $-90°$〜$90°$ | $\sin$ が単調増加する範囲に限定 |
| $\arccos$ | $0°$〜$180°$ | $\cos$ が単調減少する範囲に限定 |
| $\arctan$ | $-90°$〜$90°$ | $\tan$ が単調増加する範囲に限定。**符号だけでは象限を区別できない**（後述） |

### WIIM内での使用例

| 関数 | 使用場面 | 出典 |
|------|---------|------|
| $\arccos$ | 衛星可視半頂角 $\rho=\arccos\!\left(\dfrac{R_\oplus}{R_\oplus+h}\right)$——地平線以上で衛星が見える地球中心角 | [衛星軌道高度・周期・可視時間リファレンス](satellite_orbit_visibility.md)、[衛星軌道計算機](../tools/orbit.html) |

---

## 3. atan と atan2 の違い——象限問題を解く

$\arctan(y/x)$ は比 $y/x$ しか見ないため、$(y,x)=(1,1)$ と $(-1,-1)$ を区別できず、どちらも同じ角度を返してしまう（実際には正反対の方向）。これを解決するのが2引数版の $\mathrm{atan2}(y, x)$ で、$x,y$ の符号を個別に見て $-180°$〜$180°$ の全象限を正しく返す。

WIIMのツールでは形状生成スクリプトで実際にこの区別が使われている。

```python
a1 = np.arctan2(p1[1] - center[1], p1[0] - center[0])
a2 = np.arctan2(p2[1] - center[1], p2[0] - center[0])
```

（[tools/generate_shapes.py](../../tools/generate_shapes.py)——中心から見た2点の方位角を求める処理。単純な `arctan(y/x)` では点が中心のどちら側にあるか区別できず、図形の弧の向きを誤る）

**教訓**：方位角・進行方向など「360°全周のどこを向いているか」を求める場面では常に atan2 を使う。単純な atan は「傾き」だけが欲しく象限を問わない場面（例：勾配の大きさ）に限定するのが安全。

## 4. 「使えるが未使用」の場面——地上局から見た衛星の仰角

[衛星軌道高度・周期・可視時間リファレンス](satellite_orbit_visibility.md)は「衛星が見えるか否か」の可視半頂角 $\rho$（$\arccos$ で導出）までしか扱っていないが、「特定の地上局から衛星が何度の仰角に見えるか」を求めるには arctan（または arcsin）が必要になる。

地上局と衛星直下点（サブサテライトポイント）の間の地心中心角を $\gamma$ とすると：

$$
\tan E = \frac{\cos\gamma - \dfrac{R_\oplus}{R_\oplus+h}}{\sin\gamma}
$$

（$E$：地上局から見た衛星の仰角）

- $\gamma$ が小さい（衛星が直上に近い）ほど $E$ は $90°$ に近づく
- $\gamma = \rho$（可視半頂角ちょうど）のとき $E=0°$（地平線）となり、3章の $\arccos$ の結果と整合する
- 実務上はここで扱う比の分母・分子の符号から $\gamma>90°$（衛星が地球の裏側）を弾く必要があるため、素朴な $\arctan$ ではなく$\mathrm{atan2}$相当の場合分けが安全

この式はパラボラアンテナの地上局を実際にどの角度へ向けるかを決める、衛星通信工学の標準式でもある。可視時間リファレンスに「特定地点での仰角プロファイル」を追加する際の出発点になる。

## 5. まとめ——各関数の「代表的な仕事」

| 関数 | 代表的な仕事 |
|------|------|
| $\sin$ | 高さ・垂直成分・振幅を取り出す（波動・回転） |
| $\cos$ | 水平成分・角度依存の減衰/射影を取り出す（精度式・収束計算） |
| $\tan$ | 高さと水平距離の比＝勾配・迎角を取り出す |
| $\arcsin/\arccos$ | 比から視野角・傾斜角・位相角を逆算する |
| $\arctan$（要 atan2） | 比から方位角・仰角を逆算する。象限問題に要注意 |

三角関数は「角度→比」、逆三角関数は「比→角度」という対称な役割分担になっている。WIIMの軌道計算では、可視性や収束深さのように「比が先にあってそこから角度を知りたい」場面で逆三角関数が登場し、精度・角速度のように「角度が先にあってそこから比を知りたい」場面で三角関数が登場する傾向がある。
