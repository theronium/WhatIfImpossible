# 資料室 目録

WhatIfImpossible の世界の**内側で作られた一次資料**を収めた資料室です。
条約の条文、事故報告書、新聞記事、議事録など、作中の人物や組織が書いたという体裁の文書を扱います。

補遺ノート（[../notes/README.md](../notes/README.md)）が世界を**外から解説する**のに対し、資料室の文書は世界の**中から書かれた**ものです。
