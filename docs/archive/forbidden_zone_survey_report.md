## 1. 調査の目的

本調査は、禁域条約の発効以来はじめて認可された禁域内部の学術調査である。目的は次の三点とした。

1. 禁域内部の物理定数の偏差を、境界の外から推定するのではなく、内部で直接測定すること
2. 境界の変動の傾向を把握し、条約附属書三の改定に資すること
3. 事件の経過に関する従来の調査結果を、物理的痕跡によって検証すること

## 2. 調査の方法

調査隊の本船は境界の外側に留め、内部へは無人探査機六基と有人小型艇一隻を投入した。

条約第二条及び第五条の趣旨に照らし、本船・探査機・小型艇のいずれもカシミールフォージを搭載していない。推進はすべて通常推進による。このため、境界から内部の主要観測点までの往復に、計画立案時の想定を大きく上回る期間を要した。

## 3. 主な結果

### 3.1 内部の物理定数は「測れる」が、「内部の装置だけでは測れない」

調査の最初の段階で、計画上の前提に問題があることが判明した。

物理定数を測定する装置は、それ自体が物理定数に依存して動作する。原子時計の刻み、物差しの長さ、検出器の感度は、いずれも光速やプランク定数の値によって決まる。そのため、**内部に持ち込んだ装置で内部の定数を測ると、装置も同じだけずれるため、偏差がほとんど現れない**。

探査機二基の初期データが「偏差なし」を示したのは、この理由によるものと考えられる。

例外は、単位を持たない定数の組み合わせ（微細構造定数など）である。これは装置のずれと打ち消し合わないため、内部の装置だけでも測定できた。ただし、その偏差は検出限界をわずかに上回る程度にとどまった。

偏差を捉えるには、境界の内と外の双方に装置を置き、両者のあいだで信号を往復させて比較する必要があった。調査隊は計画を変更し、境界をまたぐ信号比較によって測定を行った。この方法によって、偏差は従来の外部推定とおおむね一致する大きさで確認された。

> この結果は、禁域の内部に「長く滞在した者」は、自分の周囲の異常に気づけない可能性を示唆している。有人小型艇の乗員は、内部滞在中に身体的な違和感を一切報告していない。

### 3.2 境界は外側へ移動しているが、一様ではない

境界は全周の平均では外側へ移動していた。ただし移動の速さは方向によって異なり、一部の区間ではわずかに内側へ後退していた。後退した区間が今後も後退を続けるかどうかは、本調査の期間からは判断できない。

附属書三の改定には、平均値ではなく区間ごとの値を用いることを勧告する。

### 3.3 失われた惑星系の痕跡

内部の主要観測点において、事件以前の惑星系の構造物と特定できる残骸は発見されなかった。

一方、内部には、境界付近と比べて物理定数の偏差がとくに大きい小領域が複数存在する。これらの位置は、事件以前の記録にある二つの主星の位置とおおむね対応している。

### 3.4 事件の経過について

調査隊は、事件時の安全系統への二重被弾が意図的なものであったかどうかについて、**これを肯定する物理的証拠も、否定する物理的証拠も得られなかった**。艦艇の残骸が発見されなかったためである。

従来の調査結論を覆す材料はない。同時に、本調査によってこの問いが決着したと解されるべきではない。

## 4. 勧告

1. 附属書三の境界は、区間ごとの観測値に基づいて改定すること
2. 今後の内部調査では、境界の内外に装置を対にして配置することを標準の手順とすること
3. 内部に長期滞在する調査員について、帰還後の健康診断に加え、外部の時計・物差しとの照合を義務づけること
4. 本報告書の要旨が「事件は偶然であったことが証明された」又は「意図的であったことが証明された」と引用されることのないよう、査察団から加盟国に注意を促すこと
