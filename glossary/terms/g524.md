# バルク空間（Bulk）

**Bulk**  素粒子・核物理学 / 素粒子物理学・宇宙論 / g524
読み: ばるくくうかん　関連: [余剰次元](g255.md), [D-ブレーン](g521.md), [ブレーンワールド](g523.md), [wiim_136](../../docs/cosmology/wiim_136.md), [wiim_137](../../docs/cosmology/wiim_137.md), [wiim_138](../../docs/cosmology/wiim_138.md)

**別名**: 高次元バルク / Bulk Space

ブレーンワールドの理論で、私たちの宇宙である膜（ブレーン）が浮かんでいる、より高い次元の空間。単に「バルク」とも呼ばれる。通常の物質は膜に閉じ込められているが、重力を伝える[重力子](g109.md)（閉じた弦）や一部の場はバルク空間の中を伝わることができる。

[ランドール＝サンドラム模型](g523.md)ではバルク空間は強く歪んでおり、その歪みが膜の上の長さやエネルギーの基準を決める。膜が[余剰次元](g255.md)の方向に曲がっていれば、膜に沿って遠い2点がバルク空間を横切ると近いこともあり、重力の信号が膜の上の光より先に届きうるという提案もある。

膜の上から見ると、バルク空間へ漏れたエネルギーは「消えた」ように、バルク空間の歪みは物質のない場所のエネルギーのように見える。余剰次元へエネルギーを逃がすことは問題の解消ではなく、帳尻をバルク空間の側で合わせることにあたる。WIIMでは、同じバルク空間を共有する膜の集まりを「宇宙系」と呼んでいる。
