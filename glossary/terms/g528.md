# プランク定数（Planck Constant）

**Planck Constant**  量子物理学 / 量子力学 / g528
読み: ぷらんくていすう　関連: [ド・ブロイ波](g202.md), [wiim_141](../../docs/physics/wiim_141.md), [wiim_143](../../docs/philosophy/wiim_143.md)

**別名**: 作用量子 / ディラック定数 / 換算プランク定数

量子論の基本定数で、光や物質のエネルギーが飛び飛びの値をとる細かさを決める。記号は h で、値は約6.626×10⁻³⁴ジュール秒（2019年からは定義値）。h を2πで割った ℏ（エイチバー、ディラック定数）もよく使われる。1900年にマックス・プランクが、熱い物体が出す光の色の分布を説明するために導入した。

単位が「エネルギー×時間」であることから、[作用](g527.md)の最小単位にあたるとみなされ、作用量子とも呼ばれる。光の粒（[光子](g064.md)）のエネルギーは振動数にプランク定数を掛けたもので、物質の波長は運動量でプランク定数を割ったもので決まる（[ド・ブロイ波](g202.md)）。

量子論では、ある運動の作用をプランク定数で割った値が、波の[位相](g242.md)の角度として現れる。作用がプランク定数に比べて桁違いに大きい日常の世界では、隣り合う経路の位相が激しく打ち消し合い、作用が極値をとる古典的な経路だけが残る。これが、量子の世界から古典力学が現れる仕組みの一つと考えられている。
