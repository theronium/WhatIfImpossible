# ブレーンワールド（Brane World）

**Brane World**  素粒子・核物理学 / 素粒子物理学・宇宙論 / g523
読み: ぶれーんわーるど　関連: [余剰次元](g255.md), [D-ブレーン](g521.md), [エキピロティック宇宙論](g522.md), [バルク空間](g524.md), [wiim_029](../../docs/physics/wiim_029.md), [wiim_136](../../docs/cosmology/wiim_136.md), [wiim_137](../../docs/cosmology/wiim_137.md), [wiim_138](../../docs/cosmology/wiim_138.md), [wiim_139](../../docs/cosmology/wiim_139.md)

**別名**: ブレーン宇宙 / ブレーン宇宙論 / ブレーンワールド理論 / ランドール＝サンドラム模型 / ADD模型

私たちの宇宙を、より高い次元の空間（[バルク空間](g524.md)）に浮かぶ3次元の膜（ブレーン）とみなす理論の総称。電子や[クォーク](g064.md)、光などの通常の物質と力は膜に閉じ込められ、重力だけが膜の外へ広がれるとする。[超弦理論](g093.md)の[D-ブレーン](g521.md)がその土台にある。

1998年のADD模型（アルカニ＝ハメド、ディモポウロス、ドヴァリ）は、重力が他の力より極端に弱い理由を、重力だけが[余剰次元](g255.md)へ薄まるためと説明した。1999年のランドール＝サンドラム模型は、強く歪んだ余剰次元を考え、余剰次元が小さくても、あるいは無限に広くても重力を膜の近くに閉じ込められることを示した。

ねじれ秤による重力の精密測定、[LHC](g074.md)の衝突実験、[重力波](g004.md)の観測はいずれも余剰次元の痕跡を見つけておらず、模型の範囲は絞り込まれつつある。WIIMではブレーン宇宙の移動（[wiim_136](../../docs/cosmology/wiim_136.md)）や崩壊からの避難（[wiim_137](../../docs/cosmology/wiim_137.md)）の前提として扱っている。
