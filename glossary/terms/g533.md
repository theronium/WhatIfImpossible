# ゴットのタイムマシン（Gott Time Machine）

**Gott Time Machine**  物理学 / 一般相対性理論 / g533
読み: ごっとのたいむましん　関連: [閉じた時間的曲線](g484.md), [wiim_142](../../docs/cosmology/wiim_142.md)

**別名**: ゴットの宇宙ひもタイムマシン / 宇宙ひもタイムマシン

1991年に[天体物理学](g124.md)者J・リチャード・ゴットが示した、[一般相対性理論](g108.md)の枠内で過去へ戻る経路を作る方法。宇宙の初期に生じたかもしれない、極めて細く重いひも状の構造（宇宙ひも）を2本用意し、互いに光速に近い速さですれ違わせる。

宇宙ひもの周りでは、空間がケーキを1切れ切り取って貼り合わせたような形になっており、ひもの両側を回る経路のどちらかが近道になる。2本のひもがすれ違うとき、それぞれの近道と相対論の同時性のずれを組み合わせることで、出発より前の場所に戻る輪の経路ができる。

一つひとつの部品は単独では因果的に安全なのに、組み合わせると時間の輪ができる、という型のタイムマシンの代表例である。その後、条件を満たすひもの組は現実の宇宙では作れない、あるいは作ろうとするとブラックホールに包まれてしまう、といった指摘がなされている。
