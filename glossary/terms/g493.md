# シュリーレン現象（Schlieren Phenomenon）

**Schlieren Phenomenon**  物理学 / 光学・流体力学 / g493
読み: しゅりーれんげんしょう　関連: [フェルマーの原理](g297.md)

**別名**: シュリーレン法 / シュリーレン写真法 / Schlieren Method

透明な媒質（気体・液体）の中に密度のムラがあると、その部分を通過する光線がわずかに屈曲し、像の歪み・揺らぎとして肉眼でも観察できる現象。夏の炎天下でアスファルトの上に見える陽炎や、ろうそくの炎の上に立ち上る空気の揺らぎが身近な例だ。名称はドイツ語で「筋・むら」を意味する Schliere に由来する。

密度が変化すると媒質の屈折率もそれに応じてわずかに変化する。温度差・組成の違い・圧力変化（音波や衝撃波の前後）のいずれも密度勾配を生む原因になりうる。屈折率が空間的に一様でない領域を光が通ると、光線は[フェルマーの原理](g297.md)（g297）に従って屈折率の高い側へわずかに曲げられ、通過後の光の進行方向にごくわずかなズレが生じる。

この角度のズレは肉眼では捉えにくいほど微小だが、「シュリーレン法」と呼ばれる光学技術で可視化できる。点光源からの光をレンズや凹面鏡で収束させ、その焦点にナイフエッジ（刃状の遮光板）を置くことで、屈折率勾配による角度のズレを明暗のコントラストへ変換する。1864年にドイツの物理学者アウグスト・テプラーが考案した。

流体力学の分野で特に重要な手法で、超音速飛行体まわりの衝撃波や境界層、燃焼・爆発時のガスの広がり、気体漏れの検知など、目に見えない密度場を非接触・非侵襲で観察する用途に広く使われている。
