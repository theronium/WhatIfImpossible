# カラビナント係数（Carabinant Coefficient）

**Carabinant Coefficient**  WIIM概念 / 架空物理定数・次元幾何学 / g501
読み: からびなんとけいすう　関連: [wiim_128](../../docs/physics/wiim_128.md)

**別名**: Ck / カラビナント限界

WhatIfImpossibleで考案された架空の無次元物理定数(記号 C_k)。登山用のフック「カラビナ」になぞらえ、異なる空間同士を接続する際の「接合力と歪みへの耐性」を表すものとして命名された。空間接続面の曲率変化と物質内部の張力エネルギーの比率として定義され、C_k>1.0では構造体が空間の歪みに負けず対象空間へ通過・固定できる(安定領域)。C_k=1.0は「カラビナント限界」と呼ばれる臨界閾値で、これを境に物質のトポロジーに不可逆な変化が生じ始める。C_k<1.0では構造体が空間のねじれに耐えられず、環状構造が球体・線状に破断・再構成される(自壊領域)。

この係数はスケールに応じて意味合いが変化する点が特徴とされる。マクロな[ワープ](g035.md)バブル境界では船体・物質の物理的形状が保たれるかを測る指標として、ミクロな量子領域([プランクスケール](g014.md)の[時空の泡](g146.md))では[量子もつれ](g062.md)のコヒーレンスが空間の[量子揺らぎ](g061.md)に耐えられるかを測る指標へとシフトする。ブラックホール近傍ではこの両者が同時に作用するため、事象の地平面近傍の潮汐力(スパゲッティ化)と、地平面上での量子情報のホログラフィックな保持・再符号化を統合的に記述できるとされ、中心[特異点](g043.md)ではC_k→0となり形状の概念自体が定義不能になる。

「完全剛体」や「[トポロジカル](g158.md)に保護された量子状態」をブラックホールに投入する思考実験では、内部の相互作用が超光速で伝播できないという特殊[相対論](g108.md)の制約や、地平面が非局所的な量子状態を内外に引き裂く因果的分断のために、C_kが対照的な経路をたどって崩壊することが示唆される(詳細は[wiim_128](../../docs/physics/wiim_128.md))。均衡状態は「[カラビナント・トポロジカル均衡](g502.md)」(g502)、均衡崩壊時の災害は「[カラビナント破断](g503.md)」(g503)としてそれぞれ独立に定義されている。
