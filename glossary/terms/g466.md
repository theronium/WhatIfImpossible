# フレア（衛星の現象）（satellite flare）

**satellite flare**  天文学・宇宙論 / 天文観測 / g466
読み: ふれあ（えいせいのげんしょう）　関連: —

人工[衛星](g123.md)が軌道上を通過する際、[太陽](g084.md)光が衛星の平らな反射面（ソーラーパネル・平面アンテナなど）に特定の角度で当たり、地上の観測者に向けて一時的に強い閃光として反射される現象。数秒から十数秒間、金星を大きく上回る明るさ（-8等級以上）に達することがあり、夜空を流れる閃光として肉眼で容易に観測できる。

最も有名な例は、平面アンテナを三枚搭載したイリジウム衛星群による「イリジウムフレア」で、地上追跡システムにより発生時刻・方向・明るさが分単位で予測可能だった。2019年以降、旧世代イリジウム衛星の退役にともない観測機会は激減したが、スターリンクなど後継大型衛星群の展開により散乱光問題として[天文学](g124.md)コミュニティでの議論が続いている。フレアは現象のタイミングと観測地点が数学的に計算できる点で、人工的な「精密天文現象」とも呼べる。
