# 軌道傾斜角（Orbital Inclination）

**Orbital Inclination**  天文学・宇宙論 / 宇宙工学・軌道力学 / g545
読み: きどうけいしゃかく　関連: —

**別名**: 傾斜角 / 軌道傾角 / inclination

中心[天体](g123.md)の赤道面に対して、衛星の軌道面がどれだけ傾いているかを表す角度。軌道6要素の一つで、記号 i で表す。0°は赤道軌道、90°は極軌道、90°を超えると自転と逆向きに回る逆行軌道となる。

傾斜角は任意に選べるように見えるが、実際には主に三つの制約で決まると考えられる。第一に物理的な制約で、地球の赤道方向の膨らみ（J2項）が軌道を少しずつ回転させるため、その回転を打ち消す[臨界傾斜角](g546.md)（約63.4°、[モルニア軌道](g357.md)）や、回転を地球の公転に同期させる約98°（[太陽同期軌道](g077.md)）のように、角度が一点に決まる場合がある。第二に発射場の緯度で、軌道面は必ず地球の中心を通るため、発射場の緯度より小さい傾斜角には直接入れない。ケープカナベラルから打ち上げる[静止トランスファ軌道](g547.md)が約28.5°なのはこのためである。第三に運用上の都合で、GPS（55°）やGLONASS（64.8°）のように、重視する緯度帯や衛星配置の最適化から選ばれる。

傾斜角を変える（軌道面を傾け直す）には、そのときの速度にほぼ比例する大きな速度変化が必要になる。このため面の変更は、軌道上で最も速度が遅い地点でまとめて行うのが基本となる。
