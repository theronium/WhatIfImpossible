# ミューオン（Muon）

**Muon**  素粒子・核物理学 / 素粒子物理学 / g507
読み: みゅーおん　関連: [ミュオン触媒核融合](g273.md), [第五の力](g115.md)

**別名**: ミュオン / μ粒子

電子と同じ性質を持ちながら質量が約207倍重い、第二世代の[レプトン](g508.md)（素粒子物理学の標準模型で物質を構成するフェルミオンに分類される粒子）。1936〜1937年に宇宙線の観測から発見された。電荷はマイナス1で、電磁相互作用と弱い相互作用に関与する一方、強い相互作用は感じない点は電子と同様である。

不安定な粒子で、平均寿命は約2.2マイクロ秒。崩壊すると電子と2個の[ニュートリノ](g064.md)になる。質量が電子より大きいぶん、[原子核](g114.md)に束縛されたときの軌道半径が約207分の1に縮小する性質を持ち、これが[ミュオン触媒核融合](g273.md)（g273）で[クーロン障壁](g271.md)を回避する鍵となっている。

近年では反ミューオンと電子からなる中性原子「ミューオニウム」を極低温まで冷却したビームとして生成し、原子[干渉計](g073.md)でアインシュタインの等価[原理](g306.md)（重力場内で全ての物体が同じ速度で落下するという原理）を第二世代粒子でも検証する試みが進んでいる。もし重力が電子と異なる大きさでミューオンに作用することが確かめられれば、標準模型の4つの[基本相互作用](g282.md)に加えて[第五の力](g115.md)（g115）が存在する証拠となりうる。
