# ラグランジアン（Lagrangian）

**Lagrangian**  物理学 / 解析力学 / g505
読み: らぐらんじあん　関連: [ネーターの定理](g089.md)

解析力学において系の運動を記述する基礎的な関数。L = T - V(運動エネルギーTからポテンシャルエネルギーVを引いたもの)として定義される。18世紀にジョゼフ=ルイ・ラグランジュがニュートン力学を再定式化する過程で導入した。

真価は「最小作用の[原理](g306.md)」と結びついたときに現れる。作用S(ラグランジアンを時間で積分した量)が停留値をとる経路が、実際に系がたどる運動経路になる。ニュートンの運動方程式と数学的に等価だが、座標系に依存しない一般性を持ち、拘束のある系でも同じ形式で[オイラー](g229.md)=ラグランジュ方程式を導出できる。

古典力学に留まらず、電磁気学・一般[相対論](g108.md)・[場の量子論](g345.md)・標準模型まで、現代物理学のほぼ全ての基礎理論がラグランジアン(密度)の形で定式化されている。対称性と保存則を結びつける[ネーターの定理](g089.md)(時間並進対称性→エネルギー保存則など)の土台でもある。
