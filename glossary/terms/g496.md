# 分散コヒーレント収穫（Distributed Coherent Harvesting）

**Distributed Coherent Harvesting**  WIIM派生技術 / 架空技術・量子真空工学 / g496
読み: ぶんさんこひーれんとしゅうかく　関連: [wiim_124](../../docs/physics/wiim_124.md), [wiim_039](../../docs/quantum/wiim_039.md)

**別名**: 収穫網 / コヒーレント収穫網

WhatIfImpossibleの思考実験（[wiim_124](../../docs/physics/wiim_124.md)）で命名された架空技術。ゼロ点エネルギー（真空のエネルギー、[カシミール効果](g009.md)g009）を単一の高温炉に集中させるのではなく、広域に分散配置した収穫ノード群から[位相](g242.md)を揃えて焦点へ集約する手法。

各ノードは[非対称カシミール板](g260.md)（g260、量子永久機関[wiim_039](../../docs/quantum/wiim_039.md)由来）を用いて仮想[光子](g064.md)を[余剰次元](g255.md)へ排出し、局所的な引力の非対称からエネルギー差分を得る。各ノードの位相情報は[コーラ粒子](g127.md)（g127）の往復によって焦点へ集約され、[ワープ](g035.md)ゲート（[wiim_074](../../docs/physics/wiim_074.md)）の[エニオン](g157.md)的ブレイド形成と同じ機構——往復回数に比例して接続が安定化する——で同期が進む。

エネルギー保存則は免除されず、全ノードの合計エネルギーは標的の静止エネルギーを下回れない（低温であって低エネルギーではない）。またノード間の位相同期には光速の制限がかかるため、当初想定された[銀河](g123.md)規模の同期は非現実的で、実用範囲は[恒星](g084.md)系規模（光時間にして数時間程度）に切り下げられる。一度この接続が安定すれば以後の抽出は低遅延で継続でき、巨大な初期投資と低コストな常時稼働が分離される経済的特徴を持つ。
