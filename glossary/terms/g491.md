# カラロン（Chalaron）

**Chalaron**  WIIM概念 / 架空粒子・一般相対性理論 / g491
読み: からろん　関連: [wiim_123](../../docs/physics/wiim_123.md), [wiim_022](../../docs/physics/wiim_022.md), [wiim_003](../../docs/physics/wiim_003.md), [wiim_023](../../docs/physics/wiim_023.md)

**別名**: 計量負粘性粒子 / 時空解錨粒子

WhatIfImpossibleの思考実験（[wiim_123](../../docs/physics/wiim_123.md)）で命名された架空粒子。ギリシャ語「χαλαρός（chalaros：緩んだ・弛んだ）」に由来する。この語は錨綱を緩める場面で使われる海事用語で、「錨を打つ」[アンキロン](g128.md)（g128、ギリシャ語 ankyra=錨）に対して「錨綱を緩める」カラロンという対構造が語源レベルで対応する。

アンキロンが時空の計量テンソルの変化率に比例した粘性抵抗を及ぼし計量の変化にブレーキをかけるのに対し、カラロンは正反対の性質を持つ——変化に抵抗するのではなく、変化を後押しして増幅する「負の計量粘性」を発揮する。量子論的に絶えず生じている微小な計量揺らぎを「種」として取り込み、巨視的な時空歪みへ増幅する架空の仕組みとして提案された。

現実の負粘性現象（二次元乱流や木星の縞状ジェット気流に見られる「負の渦粘性」）にゆるやかな足場を持つが、増幅を止める飽和機構が存在しないため暴走・発散するという根本的な問題を抱える。この暴走は[ネゴトン](g126.md)（g126）の「暴走加速」問題と同型で、エネルギー保存則との整合性が取れない。アンキロン（g128）・[コーラ粒子](g127.md)（g127）・ネゴトン（g126）と並ぶWhatIfImpossible架空粒子の一つ。
