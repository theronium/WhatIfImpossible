# 閉じた時間的曲線（Closed Timelike Curve）

**Closed Timelike Curve**  物理学 / 一般相対性理論・時空構造 / g484
読み: とじたじかんてききょくせん　関連: [wiim_001](../../docs/cosmology/wiim_001.md), [wiim_049](../../docs/physics/wiim_049.md), [wiim_118](../../docs/cosmology/wiim_118.md), [wiim_119](../../docs/cosmology/wiim_119.md)

[一般相対性理論](g108.md)の場の方程式が数学的に許す、出発点へと戻ってくる時間的（因果的に前進可能な）世界線。存在すれば、その経路をたどる観測者は自分自身の過去に到達できることになる。

[因果集合理論](g483.md)の言葉で言えば、事象間の因果的順序が満たすべき非循環性の[公理](g305.md)を破り、順序の中に環（ループ）を作る構造に相当する——単なる幾何学的な歪みではなく、因果的な「先／後」という定義そのものへの違反だ。

理論的にはゲーデル解（回転する宇宙のモデル）、チプラー円柱（無限に長い高密度回転円柱）、traversableな[ワームホール](g036.md)解などがCTCを含む厳密解として知られているが、いずれも負のエネルギー密度を持つ[エキゾチック物質](g068.md)か、非現実的な質量配置を必要とする。ホーキングの[時系列保護仮説](g485.md)は、こうした構造が実際に形成されかけると量子的な効果がそれを未然に破壊すると予想している。
