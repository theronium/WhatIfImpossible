# バリオン数生成（Baryogenesis）

**Baryogenesis**  素粒子・核物理学 / 素粒子物理学・宇宙論 / g518
読み: ばりおんすうせいせい　関連: [バリオン数](g516.md), [レプトン数](g517.md), [反物質](g067.md), [CP対称性](g156.md), [wiim_103](../../docs/physics/wiim_103.md), [wiim_104](../../docs/physics/wiim_104.md)

**別名**: バリオジェネシス / サハロフの3条件 / サハロフ条件 / バリオン非対称性 / 物質・反物質非対称性 / レプトジェネシス

物質と[反物質](g067.md)が同量あったはずの初期宇宙から、物質だけが残った現在の宇宙がどう生まれたかを説明する過程。観測によれば、初期宇宙には反粒子約10億個に対して粒子が1個だけ多く、残りは対消滅して光になったと考えられている。

1967年にアンドレイ・サハロフは、この偏りが生じるための3条件を示した。①[バリオン数](g516.md)が破れる反応がある、②C対称性と[CP対称性](g156.md)が破れていて粒子と反粒子の振る舞いに差がある、③宇宙が熱平衡から外れている（平衡では生成と逆反応が釣り合い偏りが消える）。

標準模型は3条件を形式的に備えるが、CPの破れが小さすぎて量が足りない。そこで[大統一理論](g093.md)に基づく案、ヒッグス場の相転移で生じるとする電弱[バリオン](g114.md)数生成、重い[ニュートリノ](g064.md)の崩壊でまず[レプトン数](g517.md)の偏りを作り、それを超高温の反応でバリオン数へ変換するレプトジェネシスなどが提案されている。どれが正しいかは決着していない。
