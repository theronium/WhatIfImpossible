# 多重実現可能性（Multiple Realizability）

**Multiple Realizability**  哲学・存在論 / 心の哲学 / g538
読み: たじゅうじつげんかのうせい　関連: [組織不変性の原理](g539.md), [wiim_143](../../docs/philosophy/wiim_143.md)

**別名**: 多重実現 / 多重実現性

心の状態は、さまざまな異なる物質の上で実現できるという考え方。1960年代に哲学者ヒラリー・パトナムが、痛みという状態がヒト、タコ、さらには地球外生命や機械でも、それぞれ違う物質の仕組みで実現されうると論じたことに始まる。

この考えに立つと、心は特定の物質（脳の神経細胞）と同じものではなく、物質がどのように組織され、どのように働くかというパターンだということになる。同じソフトウェアが違う機種のコンピュータで動くのと似た関係である。

多重実現可能性は、心を脳から別の基盤へ移す意識移植や精神転送の構想に理論的な足場を与える。一方で、心が物質とは別の基盤に移せるとしても、それは心が因果の連なりから自由になることを意味しない。移せるのは基盤であって、因果の履歴そのものではない、という整理がありうる。
