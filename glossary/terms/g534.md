# ガオ＝ウォルドの定理（Gao–Wald Theorem）

**Gao–Wald Theorem**  物理学 / 一般相対性理論 / g534
読み: がおうぉるどのていり　関連: [エキゾチック物質](g068.md), [ブレーンワールド](g523.md), [wiim_136](../../docs/cosmology/wiim_136.md), [wiim_142](../../docs/cosmology/wiim_142.md)

**別名**: ガオ・ウォルドの定理 / 重力的時間遅延定理

2000年にシジェ・ガオとロバート・ウォルドが証明した、重力による時間の遅れに関する[定理](g304.md)。負のエネルギーを持たないふつうの物質（ヌルエネルギー条件を満たす物質）だけでできたある種の時空では、重力は信号を必ず遅らせる側に働き、時空の内部を通る経路が境界に沿う経路より早く着くことはないことを示した。

直観的には、重力はいつも引力として光を曲げ、遠回りさせるため、重力を使って近道を作ることはできない、という主張にあたる。[反ド・ジッター空間](g532.md)では、内部を通る信号が境界の信号を追い越せないことを保証し、AdS/CFT対応で境界の理論の因果が保たれる根拠にもなっている。

逆に言えば、重力で近道を作るには、この定理の前提である「負のエネルギーがない」という条件を破る必要がある。[ワームホール](g036.md)や[アルクビエレドライブ](g035.md)、[余剰次元](g255.md)を経由する近道が、いずれも[エキゾチック物質](g068.md)を必要とする理由の一つを、この定理が与えている。
