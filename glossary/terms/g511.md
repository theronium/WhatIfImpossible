# ボゾン星（Boson Star）

**Boson Star**  仮説・未観測の粒子 / 理論天体物理学・一般相対論 / g511
読み: ぼぞんせい　関連: [wiim_135](../../docs/physics/wiim_135.md)

スピン0の仮説的スカラー場のような、ボース統計に従う粒子だけで構成されると仮定される自己重力天体。実在は確認されておらず、一般[相対論](g108.md)とスカラー場方程式を組み合わせた理論的解として研究されている。

白色矮星や[中性子星](g084.md)は、それぞれ電子・[中性子](g114.md)というフェルミオンの[パウリの排他原理](g060.md)に由来する[縮退](g281.md)圧によって自己重力に対抗し、一定の大きさを保っている。[ボース粒子](g064.md)には排他[原理](g306.md)が適用されないため、ボゾン星には縮退圧という支えが存在せず、自己重力に対抗できるのはハイゼンベルクの[不確定性原理](g311.md)に由来する弱い「量子圧」だけになる。

自己相互作用を持たない最小ボゾン星（ミニ・ボゾン星）が支えられる質量には、この量子圧の弱さに起因する低い上限（カウプ限界）がある。スカラー場に反発的な自己相互作用を加えれば[中性子星](g123.md)に匹敵する質量まで安定化できると理論的に示されているが、それでも縮退圧という土台を欠く点は変わらない。[ダークマター](g056.md)候補やブラックホールの代替モデルとしても議論される。
