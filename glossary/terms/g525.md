# クラスニコフ管（Krasnikov Tube）

**Krasnikov Tube**  SF概念 / 一般相対性理論・SF / g525
読み: くらすにこふかん　関連: [ワープドライブ / アルクビエレドライブ](g035.md), [ワームホール](g036.md), [ダークエネルギーアンカーホール](g526.md), [wiim_136](../../docs/cosmology/wiim_136.md), [wiim_140](../../docs/cosmology/wiim_140.md), [wiim_142](../../docs/cosmology/wiim_142.md)

**別名**: クラスニコフチューブ / Krasnikov Tube

1995年にセルゲイ・クラスニコフが提案した、[一般相対性理論](g108.md)の枠内で超光速的な往来を可能にする時空の構造。宇宙船が目的地へ向かう最初の旅は光速以下で行い、その経路に沿って時空を加工した管を残していく。管の中では光円錐が傾いており、帰りの旅では、出発地から見て出発直後に戻ってくることができる。

[アルクビエレドライブ](g035.md)（g035）では、泡の前方が船から因果的に切り離されていて、船の側から泡を制御できない問題があった。クラスニコフ管は往路で自ら敷いていくインフラなので、この問題を避けられる点が特徴だ。

ただし1997年にエベレットとローマンは、管の維持に膨大な負のエネルギーが必要なことを示した。さらに向きの違う2本の管を組み合わせると、[閉じた時間的曲線](g484.md)ができてタイムマシンになることも指摘されている。WIIMの[ダークエネルギーアンカーホール](g526.md)は、同じ構造を持つ。
