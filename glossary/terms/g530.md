# マーゴラス＝レヴィティンの定理（Margolus–Levitin Theorem）

**Margolus–Levitin Theorem**  量子物理学 / 量子情報・計算の物理学 / g530
読み: まーごらすれゔぃてぃんのていり　関連: [ランダウアー原理](g172.md), [wiim_141](../../docs/physics/wiim_141.md)

**別名**: マーゴラス・レヴィティンの定理 / 量子速度限界

量子系がある状態から、それと完全に区別できる別の状態へ移るまでに、最低限かかる時間を与える[定理](g304.md)。1998年にノーマン・マーゴラスとレフ・レヴィティンが示した。その最短時間は、系が持つ平均エネルギー（最低エネルギーからの差）に反比例する。

言い換えると、1ステップの状態変化には「エネルギー×時間」、つまり[作用](g527.md)がおよそ[プランク定数](g528.md)の数分の一以上必要になる。エネルギーは状態変化の速さの上限を決め、一定時間内に起こりうるステップ数の上限は、積み上がった作用の量で決まる。量子速度限界と呼ばれる一連の結果の代表例である。

2000年、物理学者セス・ロイドはこの定理を用いて、質量1キログラムの物質で可能な計算速度の上限を毎秒およそ10⁵⁰回と見積もった（究極のラップトップ）。情報の消去に最低限の熱が要るとする[ランダウアー原理](g172.md)が「忘れる」ことのコストをエネルギーで測るのに対し、この定理は「状態を変える」ことのコストを作用で測る。
