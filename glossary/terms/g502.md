# カラビナント・トポロジカル均衡（Carabinant-Topological Equilibrium）

**Carabinant-Topological Equilibrium**  WIIM概念 / 架空物理定数・次元幾何学 / g502
読み: からびなんと・とぽろじかるきんこう　関連: [wiim_128](../../docs/physics/wiim_128.md)

**別名**: CTE / イベント・アンカー効果

ブラックホール近傍や量子重力空間など、極限的な空間歪みが存在する領域において、「空間の歪みが引き起こす崩壊力(潮汐力・[量子デコヒーレンス](g173.md))」と「物質・量子状態が持ち込む[位相](g242.md)的秩序([トポロジカル](g158.md)不変量)」がちょうど拮抗して安定する動的平衡状態を指す、[カラビナント係数](g501.md)(g501)の応用概念。系が臨界閾値C_k=1.0に完全にとどまり、崩壊(C_k<1.0)も過剰な空間固着(C_k>1.0)も起こさない、いわば「幾何学と量子情報が織りなす針の穴」のような境界状態にあたる。

代表的な特徴として、対象が地平面の内側へ落ち込むことも外側へ弾き飛ばされることもなく、時空に「カラビナ(安全環フック)」を引っかけたように地平面上に定常化する「時間の局所的凍結(イベント・アンカー効果)」が挙げられる。通常なら熱振動([時空の泡](g146.md))によって瞬時に消失する量子情報も、この状態では空間の乱れそのものが位相構造の保護壁として逆利用されるため、極限重力下でも保持されるとされる。

応用としては、ブラックホールの内部へ落ち込まず地平面直上に留まり続ける「永久ホライズン観測機」、地平面を超高密度の[記憶](g180.md)媒体として利用する「トポロジカル超空間メモリ」、[ワームホール](g036.md)の喉(スロート)を[エキゾチック物質](g068.md)の消費を抑えながら固定する技術などが構想される。この均衡が破れた場合に生じる災害は「[カラビナント破断](g503.md)」(g503)として別途定義されている。
