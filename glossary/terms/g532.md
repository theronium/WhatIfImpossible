# 反ド・ジッター空間（Anti-de Sitter Space）

**Anti-de Sitter Space**  物理学 / 一般相対性理論・弦理論 / g532
読み: はんどじったーくうかん　関連: [ブレーンワールド](g523.md), [バルク空間](g524.md), [wiim_142](../../docs/cosmology/wiim_142.md)

**別名**: AdS空間 / AdS / 反ドジッター空間

負の宇宙定数を持つ、最も対称性の高い時空。名前は、正の宇宙定数を持つ時空を研究したオランダの[天文学](g124.md)者ウィレム・ド・ジッターに由来する。私たちの宇宙は正の宇宙定数（[ダークエネルギー](g218.md)）を持つため反ド・ジッター空間ではないが、理論物理学の多くの場面で重要な舞台になる。

反ド・ジッター空間には、全体が重力の谷のようにふるまう性質がある。ある点から質量のある粒子をどんな速さで投げ出しても、ほぼ同じ時間で元の場所へ戻ってくる。強く投げると遠くまで行くだけで、往復の時間は変わらない。一方、光は有限の時間で空間の果て（境界）まで届く。

[超弦理論](g093.md)のAdS/CFT対応では、反ド・ジッター空間の重力理論が、その境界に住む重力を含まない量子の理論と同じ物理を表すとされる。ランドール＝サンドラム型の[ブレーンワールド](g523.md)では、膜の外の[バルク空間](g524.md)が反ド・ジッター空間の形に強く歪んでおり、その歪みが膜の上の長さやエネルギーの基準を決める。
