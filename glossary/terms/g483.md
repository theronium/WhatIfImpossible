# 因果集合理論（Causal Set Theory）

**Causal Set Theory**  量子物理学 / 量子重力理論 / g483
読み: いんがしゅうごうりろん　関連: [wiim_118](../../docs/cosmology/wiim_118.md)

時空を連続体としてではなく、事象と事象を結ぶ因果的な順序関係の集合として捉え直す量子重力理論の候補。ラファエル・ソーキンらが提唱した。基本[原理](g306.md)は「Order + Number = Geometry」というスローガンに要約される——事象間の因果的順序（どちらが先に影響を及ぼせるか）と、その間に挟まる事象の個数（体積の代わり）さえ与えられれば、距離や曲率を含む滑らかな幾何学を事後的に復元できるという主張だ。

標準的な因果集合は、点をポアソン過程でランダムに撒布する「スプリンクリング」という手続きで構成される。撒く密度が[プランクスケール](g014.md)程度であれば、大域的には連続時空として振る舞う。

興味深いことに、ランダムに生成した半順序の大半は多様体的な秩序を持たない扁平なポセット（クレイトマン＝ロスチャイルドの[定理](g304.md)が示す“KRポセット”）になり、私たちの滑らかな4次元時空はむしろ例外的な配置だと考えられている。また規則正しい格子で[離散](g232.md)化すると[ローレンツ対称性](g063.md)が破れてしまうが、ポアソン撒布はその確率分布自体がローレンツ不変になる（ボンベリ＝ヘンソン＝ソーキンの定理）——規則性ではなくランダム性の側が対称性を守るという[逆説](g113.md)的な性質を持つ。
