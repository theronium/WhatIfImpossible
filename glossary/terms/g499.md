# 臨界半径（Critical Bubble Radius）

**Critical Bubble Radius**  物理学 / 統計力学・相転移論 / g499
読み: りんかいはんけい　関連: [真空崩壊](g012.md), [wiim_125](../../docs/physics/wiim_125.md)

**別名**: 核形成臨界半径 / Rc

一次相転移における泡核形成理論の基礎概念。転移領域（泡）の半径Rに対し、体積エネルギーの得（密度差Δρに比例し$R^3$で効く）と表面エネルギーの損（表面張力σによる境界のコストで$R^2$で効く）がせめぎ合う。

小さい泡では表面コストが体積の得に勝るため、泡は自発的に潰れて周囲に飲み込まれる。この釣り合いから決まる臨界半径 $R_c = 2\sigma / (\Delta\rho c^2)$ を超えて初めて体積の得が表面コストに勝ち、泡は際限なく成長する。臨界半径未満は埋め戻される運命、以上は不可逆に成長する運命——中間はないと考えられている。

過冷却水の凍結核形成と同じ数学的構造であり、[真空崩壊](g012.md)（偽の真空から真の真空への転移）の核形成確率を左右する中心的パラメータでもある。ブラックホールの地平面近傍の強い時空曲率が、この臨界半径に到達するのに必要な障壁（ユークリッド作用）を肩代わりして下げるという触媒機構が理論的に示唆されている。
