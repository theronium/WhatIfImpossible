# 経路積分（Path Integral）

**Path Integral**  量子物理学 / 量子力学・場の量子論 / g529
読み: けいろせきぶん　関連: [wiim_141](../../docs/physics/wiim_141.md)

**別名**: ファインマンの経路積分 / 経路積分法

[量子力学](g253.md)の定式化の一つ。1948年にリチャード・ファインマンが、ディラックの着想を発展させて完成させた。粒子がある点から別の点へ移るとき、ただ一つの経路を通るのではなく、考えうるあらゆる経路を同時にたどると考える。

それぞれの経路には、その経路の[作用](g527.md)を[プランク定数](g528.md)で割った角度の[位相](g242.md)が割り当てられ、すべての経路の寄与を足し合わせたものが、粒子がその点に到達する確率の振幅になる。日常の大きさの物体では作用がプランク定数より桁違いに大きいため、ほとんどの経路は位相が打ち消し合い、作用が極値をとる古典的な経路の近くだけが生き残る。最小作用の[原理](g306.md)は、この打ち消し合いの結果として理解できる。

経路積分は、[場の量子論](g345.md)や素粒子の標準模型の計算、統計力学、量子重力の研究でも中心的な道具として使われる。この描像では、世界の基本単位は「ある瞬間の状態」ではなく「始まりから終わりまでの履歴」であり、物理学の見方そのものに影響を与えてきた。
