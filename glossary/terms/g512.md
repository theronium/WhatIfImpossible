# クォークの閉じ込め（Quark Confinement）

**Quark Confinement**  素粒子・核物理学 / 素粒子物理学・量子色力学 / g512
読み: くぉーくのとじこめ　関連: [ゲージ理論](g492.md), [弦切断](g513.md), [格子ゲージ理論](g515.md), [エネルギー紐](g131.md), [wiim_021](../../docs/physics/wiim_021.md)

**別名**: カラー閉じ込め / 色閉じ込め / カラーコンファインメント / Color Confinement

クォークや[グルーオン](g064.md)のように「色荷（カラー）」を持つ粒子は単独では取り出せず、色荷が打ち消し合った陽子・中性子・中間子などの複合粒子（ハドロン）としてしか観測されない、という強い力の性質。量子色力学（SU(3)の[ゲージ理論](g492.md)）の中心的な特徴とされる。

電磁気力と違い、クォーク間の力は離しても弱まらない。[グルーオン](g114.md)場が細い管（フラックスチューブ）状に絞り込まれ、そのエネルギーが長さにほぼ比例して増えるためだ。張力は10トン重を超えると見積もられる。十分に引き伸ばすと紐は[弦切断](g513.md)によって新しいクォーク対を生んでちぎれる。逆に近距離では力が弱まり、クォークはほぼ自由に振る舞う（漸近的自由性）。

実験や[格子ゲージ理論](g515.md)の計算で強く支持される一方、理論からの厳密な証明はなく、関連問題は[ミレニアム懸賞問題](g102.md)の一つとされる。WIIMでは[エネルギー紐](g131.md)（[wiim_021](../../docs/physics/wiim_021.md)）の物理的モデルとして参照している。
