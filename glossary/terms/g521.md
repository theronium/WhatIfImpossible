# D-ブレーン（D-brane）

**D-brane**  素粒子・核物理学 / 超弦理論 / g521
読み: でぃーぶれーん　関連: [超弦理論](g093.md), [余剰次元](g255.md), [エキピロティック宇宙論](g522.md), [無の泡](g520.md), [wiim_136](../../docs/cosmology/wiim_136.md), [wiim_137](../../docs/cosmology/wiim_137.md)

**別名**: Dブレーン / ディリクレ膜 / 反ブレーン

[超弦理論](g093.md)（g093）に現れる、開いた弦の端がとどまれる面。名前のDは、弦の端の位置を固定する数学的条件（ディリクレ境界条件）に由来する。1995年にジョセフ・ポルチンスキーが、D-ブレーンが質量と電荷を持つ実体であることを示し、超弦理論の研究が大きく進んだ。

両端がブレーンに固定された開いた弦はブレーンから離れられないが、端を持たない閉じた弦（[重力子](g109.md)など）は外の高次元空間（バルク）へ出られる。[電子](g064.md)や光がブレーンに閉じ込められ、重力だけが[余剰次元](g255.md)（g255）へ漏れ出すというブレーンワールド理論の描像は、この性質に基づいている。

ブレーンには向きが逆の反ブレーンがあり、両者が出会うと対消滅してブレーンそのものが消え、エネルギーは閉じた弦の放射になると考えられている。WIIMではブレーン宇宙の移動（[wiim_136](../../docs/cosmology/wiim_136.md)）や崩壊（[wiim_137](../../docs/cosmology/wiim_137.md)）の前提として参照している。
