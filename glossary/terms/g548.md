# 準粒子（Quasiparticle）

**Quasiparticle**  量子物理学 / 物性物理学・場の量子論 / g548
読み: じゅんりゅうし　関連: [wiim_146](../../docs/cosmology/wiim_146.md)

固体や液体のように多数の粒子が相互[作用](g527.md)している系で、その集団的な揺れや励起を、あたかも1個の独立した粒子のように扱ったもの。決まったエネルギーと運動量を持ち、生成・消滅・散乱など粒子のように振る舞うが、系の外へ取り出すことはできない。

代表例は結晶格子の振動を量子化した[フォノン](g365.md)（音子）で、磁性体の中を伝わる向きの揺れであるマグノンなどもある。[超伝導](g197.md)や[超流動](g428.md)の性質も準粒子の振る舞いとして説明される。

真空中の[光子](g064.md)そのものも、より基礎的な「媒質」の準粒子ではないかという「[創発](g175.md)」の議論があり、量子的にもつれた格子から光子と同じ性質の励起が現れる模型（ストリングネット凝縮）が知られる。[wiim_146](../../docs/cosmology/wiim_146.md) では光子を「空間の音の粒」とみなす発想の足がかりとして扱っている。ただし、そうした媒質の存在は確かめられていない。
