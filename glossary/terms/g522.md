# エキピロティック宇宙論（Ekpyrotic Universe）

**Ekpyrotic Universe**  天文学・宇宙論 / 宇宙論・超弦理論 / g522
読み: えきぴろてぃっくうちゅうろん　関連: [D-ブレーン](g521.md), [余剰次元](g255.md), [wiim_136](../../docs/cosmology/wiim_136.md), [wiim_137](../../docs/cosmology/wiim_137.md)

**別名**: エキピロティック宇宙 / エクピロティック宇宙論 / サイクリック宇宙論 / Cyclic Universe

[ビッグバン](g082.md)を、高次元空間（バルク）の中で2枚の膜（[D-ブレーン](g521.md)）が衝突した出来事として説明する宇宙論。2001年にジャスティン・クーリー、バート・オヴルト、ポール・スタインハート、ニール・トゥロックが提唱した。名前はギリシャ語で「大火から」を意味し、宇宙が火に包まれては生まれ変わるという古代ストア派の宇宙観に由来する。

膜どうしが近づき、衝突した運動エネルギーが高温の放射に変わって、熱いビッグバンが始まるとされる。インフレーション理論とは別の仕組みで、宇宙が一様で平坦に見える理由を説明しようとする。

発展版のサイクリック宇宙論（2002年）では、膜は衝突して跳ね返り、再び離れては衝突することを繰り返す。宇宙の中身は衝突のたびにリセットされるが、膜そのものは存続し続ける。観測的な検証は決着していない。
