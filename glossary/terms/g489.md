# 自己創造宇宙（Self-Creating Universe）

**Self-Creating Universe**  天文学・宇宙論 / 宇宙論・量子重力 / g489
読み: じこそうぞううちゅう　関連: [wiim_119](../../docs/cosmology/wiim_119.md)

J.リチャード・ゴットと李立新が1998年の論文「Can the Universe Create Itself?」で提唱した宇宙論モデル。標準的な[ビッグバン](g082.md)理論は、宇宙の起源に因果的な先行者を持たない「最初の事象」を要求するが、このモデルはその構造的な居心地の悪さを回避しようとする。

極めて初期の宇宙に[閉じた時間的曲線](g484.md)（CTC）を許す領域を置き、そこから通常のインフレーションが始まるという筋書きを描く。この場合、宇宙の因果構造は始点のある半直線ではなく環（ループ）を成し、「最初の事象」を遡ろうとすると常に同じループ上の別の事象に行き着く——宇宙は文字通り自分自身の“母”になる。

真の第一原因を必要としない点で[無境界仮説](g486.md)と動機を共有するが、滑らかに閉じるのではなく、あえて因果順序に環を混入させることで始まりの矛盾を解消する点で対照的なアプローチだ。
