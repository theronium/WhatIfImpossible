# 赤の女王仮説（Red Queen Hypothesis）

**Red Queen Hypothesis**  生物学・進化 / 進化生物学 / g476
読み: あかのじょおうかせつ　関連: —

生物種は周囲の環境（捕食者・被食者・寄生者・宿主など）が絶えず進化し続けるため、自らも常に進化し続けなければ相対的な適応度を維持できない、とする進化生物学の仮説。1973年に進化生物学者リー・ヴァン・ヴェーレンが提唱した。

名称はルイス・キャロル『鏡の国のアリス』の赤の女王の台詞「その場にとどまるためには、全力で走り続けなければならない」に由来する。捕食者が足を速めれば被食者も足を速めねばならず、免疫系が病原体に対抗すれば病原体も新たな回避手段を進化させる——このような競争的共進化（コエボリューション）は、絶対的な性能向上ではなく、あくまで相手との相対的な優位を保つための終わりのない軍拡競争として進化を駆動する。

この仮説は、有性生殖が無性生殖より広く維持されている理由（遺伝的多様性を高め、寄生者の追随を振り切りやすくするため）を説明する有力な説の一つとしても引用される。
