# 作用（物理量）（Action）

**Action**  物理学 / 解析力学・場の理論 / g527
読み: さよう　関連: [ネーターの定理](g089.md), [固有時間](g174.md), [wiim_141](../../docs/physics/wiim_141.md)

**別名**: 作用 / 作用積分 / アクション

物体や場が、ある時刻からある時刻までにたどった運動の履歴全体に対して一つの数を割り当てる量。単位は「エネルギー×時間」（ジュール秒）で、[プランク定数](g528.md)や角運動量と同じ次元を持つ。記号には S がよく使われる。

自然界の運動は、考えうる経路のうち作用が極値（多くの場合は最小）をとる経路として実現する。これを最小作用の[原理](g306.md)という。ニュートン力学、電磁気学、[一般相対性理論](g108.md)、素粒子の標準模型は、いずれも一つの作用を書き下すことで表現でき、現代物理学で最も根本に置かれる量の一つとされる。

エネルギーや運動量は、作用から導かれる量として位置づけられる。作用が時間をずらしても変わらないことからエネルギー保存が、場所をずらしても変わらないことから運動量保存が導かれる（[ネーターの定理](g089.md)）。静止した粒子の作用は、質量とその粒子自身が経験する時間（[固有時間](g174.md)）の積に比例して積み上がるため、質量は「作用が刻まれる速さ」と読むこともできる。

エネルギーと違って作用には保存則がなく、ある瞬間に「どれだけあるか」を言える量でもない。また、物理を変えずに作用の値に足し引きできる部分があるため、絶対値は観測できず、意味を持つのは経路どうしの差である。量子論では、作用はプランク定数を単位とした波の[位相](g242.md)として現れ、その差が干渉として観測される。
