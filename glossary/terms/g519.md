# 世界線（World Line）

**World Line**  物理学 / 相対性理論 / g519
読み: せかいせん　関連: [固有時間](g174.md), [閉じた時間的曲線](g484.md), [パラレルワールド](g142.md), [wiim_090](../../docs/cosmology/wiim_090.md), [wiim_037](../../docs/physics/wiim_037.md), [wiim_119](../../docs/cosmology/wiim_119.md)

**別名**: ワールドライン / Worldline

物体が時空の中をたどる軌跡。空間3次元と時間1次元をあわせた4次元の時空では、止まっている物体も時間方向に伸びる1本の線として表される。[相対性理論](g108.md)には宇宙共通の時間軸がなく、物体ごとの世界線に沿って刻まれる[固有時間](g174.md)が物理的な時間とされる。動く物体の世界線は傾き、時計の進み方も変わる。どの世界線も光円錐の内側を通る必要があり、これが光速を超えられないという[因果律](g017.md)の制約にあたる。

世界線自体は未来の向きを決めない。どちらを未来とするかは、[エントロピー](g008.md)が増える向きなど中身の性質で決まると考えられている。自分の過去に戻る世界線は[閉じた時間的曲線](g484.md)と呼ばれる。

SF作品『シュタインズ・ゲート』などでは、世界線を「宇宙の歴史の1本」の意味で使い、過去改変で別の世界線へ移ると描く。これは物理学の用法とは異なり、[多世界解釈](g162.md)の[パラレルワールド](g142.md)の枝に近い。WIIMの記事でも両方の意味が使われている。
