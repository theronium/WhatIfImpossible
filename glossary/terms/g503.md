# カラビナント破断（Carabinant Rupture）

**Carabinant Rupture**  WIIM概念 / 架空物理定数・次元幾何学 / g503
読み: からびなんとはだん　関連: [wiim_128](../../docs/physics/wiim_128.md)

**別名**: カラビナント・ノイズ / カラビナント瘢痕

「[カラビナント・トポロジカル均衡](g502.md)」(g502)が崩壊した際、空間の曲率エネルギーと量子状態の[トポロジカル](g158.md)張力が一気に解放されて生じる、巨視的な空間構造の破裂・再構成災害。[カラビナント係数](g501.md)(g501)がC_k<1.0へ暴落した場合、C_k>1.0への過剰固着(オーバーシュート)を起こした場合のどちらでも発生しうる。

発現は数ミリ秒単位で連鎖する3段階のフェーズとして描かれる。まず質量過剰投入や量子不確定性のスパイクにより均衡が崩れ、固定されていたトポロジカル情報網が引きちぎれる・急収縮する「[位相](g242.md)剪断」が起こる。続いて歪められていた空間が抑え込んでいたポテンシャルエネルギーを解放し、平坦な状態へ急激に復元しようと跳ね返る「反転弾性波」が生じる。最後に解放された[重力波](g004.md)と位相エネルギーがショックウェーブとなり、微視的な[時空の泡](g146.md)を巨視的スケールへ引き伸ばしながら周囲へ拡大する「トポロジカル破裂」に至る。

主な影響として、物質の形状・接続関係を保つ幾何学的ルールが一時的に無効化され構造体が再構成される「位相崩壊域」、地平面に保持されていた量子情報・エネルギーが指向性を持つガンマ線・重力波フラッシュとして放出される「事象の地平面の不連続飛散」、破断後の領域で空間の柔軟性が失われ[ワープ航法](g035.md)や超空間通信が不成立・著しく遅延する「カラビナント瘢痕」が挙げられる。超高度文明やブラックホール発電プラントにおける最悪の想定災害(メルトダウン)として位置づけられ、予兆である係数のゆらぎ(通称「カラビナント・ノイズ」)を検知した時点でトポロジカル状態を安全に[デコヒーレンス](g173.md)させ熱として逃がす「安全弁システム(位相降下装置)」の運用が予防策とされる。
