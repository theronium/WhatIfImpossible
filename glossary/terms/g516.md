# バリオン数（Baryon Number）

**Baryon Number**  素粒子・核物理学 / 素粒子物理学 / g516
読み: ばりおんすう　関連: [レプトン数](g517.md), [バリオン数生成](g518.md), [反物質](g067.md), [原子核の階層構造](g114.md), [wiim_135](../../docs/physics/wiim_135.md), [wiim_124](../../docs/physics/wiim_124.md)

**別名**: 重粒子数 / B数

陽子・中性子などの[バリオン](g114.md)（重粒子）の「個数」を表す量子数。[クォーク](g064.md)1個に＋1/3、反クォークに−1/3を割り当てるため、クォーク3個からなる陽子・中性子は＋1、反陽子は−1、クォークと反クォークの組である中間子は0、電子などの[レプトン](g508.md)も0になる。

これまで観測されたすべての反応でバリオン数は保存されている。エネルギーから陽子を作ると必ず反陽子も生まれ、ベータ崩壊で陽子が単独で生まれるのは中性子のバリオン数を引き継ぐからだ。陽子が安定なのも、より軽いバリオンが存在せず崩壊先がないためと説明される。

ただし標準模型でも超高温では破れうることが知られ、[大統一理論](g093.md)は陽子崩壊を予言する。スーパーカミオカンデは陽子の寿命を10³⁴年以上と制限しているが、崩壊は未観測だ。宇宙に[反物質](g067.md)がほとんど残っていない事実は、過去のどこかでバリオン数が破れた証拠と考えられている（[バリオン数生成](g518.md)）。
