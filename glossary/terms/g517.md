# レプトン数（Lepton Number）

**Lepton Number**  素粒子・核物理学 / 素粒子物理学 / g517
読み: れぷとんすう　関連: [バリオン数](g516.md), [バリオン数生成](g518.md), [反物質](g067.md)

**別名**: 軽粒子数 / L数

電子・[ミューオン](g507.md)・タウ粒子と3種類の[ニュートリノ](g064.md)からなる[レプトン](g508.md)（軽粒子）の「個数」を表す量子数。レプトンに＋1、その反粒子に−1を割り当てる。

電子をエネルギーから作ると陽電子も生まれるのはレプトン数（と電荷）の保存のためだ。一方ベータ崩壊では電子が単独で生まれるが、同時に反ニュートリノ（−1）が出てレプトン数の合計は0に保たれる。

かつては電子・ミューオン・タウの種類ごとの数も個別に保存されると考えられたが、1998年にスーパーカミオカンデがニュートリノ振動を確認し、種類ごとの保存は破れていることがわかった。合計のレプトン数は今のところ破れが見つかっていない。ニュートリノが自分自身の反粒子（[マヨラナ粒子](g217.md)）なら合計も破れ、ニュートリノを放出しない二重ベータ崩壊が起きるはずで、各国で探索が続いている。この破れはレプトン数を起点とする[バリオン数](g516.md)生成のシナリオ（[レプトジェネシス](g518.md)）の鍵ともされる。
