# シュウィンガー機構（Schwinger Mechanism）

**Schwinger Mechanism**  素粒子・核物理学 / 量子電磁力学・場の量子論 / g514
読み: しゅうぃんがーきこう　関連: [量子トンネル効果](g097.md), [量子揺らぎ](g061.md), [弦切断](g513.md), [真空崩壊](g012.md)

**別名**: シュウィンガー効果 / Schwinger Effect / シュウィンガー対生成 / シュウィンガー限界

極めて強い一様な電場の中で、真空から電子と陽電子の対が自然に生まれる、と量子電磁力学が予言する現象。1951年にジュリアン・シュウィンガーが定式化した。

通常の真空には粒子対を実際に取り出すエネルギーがない。しかし電場が強ければ、電子と陽電子を引き離す向きに電場が仕事をし、対生成のエネルギー障壁を[量子トンネル効果](g097.md)で抜けられるようになる。生成率は電場が弱まると指数関数的に小さくなり、臨界電場（シュウィンガー限界）はおよそ10¹⁸ V/mと、現在の最強レーザーでも届かない。静電場による本来の対生成は未観測で、グラフェンなど物性系での類似現象の観測にとどまる。

量子色力学では、紐の中の強い色電場が紐全体で一様に[クォーク](g064.md)対を生むという、[弦切断](g513.md)の標準的な描像に使われてきた。2026年の捕捉イオン量子シミュレータ実験では紐の端から切断が進む経路が観測され、この描像だけでは捉えきれない可能性が示唆されている。
